# 京东联盟适配层

`client.py` 实现签名、请求和响应解析。当前主流程为 `goods.jingfen.query` 读取精选池，再以 `goodsReq={sceneId:1,itemIds:[...]}` 调用 `goods.bigfield.query`。旧普通 SKU/关键词入口保留但不在界面使用。

真实联调需要确认账号权限、接口文档、分页与频率限制、脱敏响应样例。
商品 ID、品牌、型号、店铺、价格口径、商品链接的实际字段以该接口为准。
不得假设接口包含完整硬件参数，也不得将缺失参数填成虚构数据。

密钥只从后端配置读取。原始记录保存业务响应，不保存请求签名、Token 或密钥。
