# 大品牌配件采集

原始商品与价格快照保存在后端配置的 SQLite 数据库中，不删除旧记录。
`server/scripts/export_priority_hardware.py` 生成同一存储目录下的
`priority_hardware.json`，仅保留接口 `owner=g` 确认的京东自营商品。
京东自营表示平台经营，并不表示品牌直营。具体型号和 SKU 仍待核验，不自动覆盖前端配件库。
未验证店铺身份的品牌候选隔离到 `priority_hardware_review.json`；
逐店身份检查结果保存到 `merchant_verification_audit.json`。

## 本轮搜索范围

淘宝接口均启用天猫筛选，每组关键词最多 3 页，每页 20 条，遵守现有冷却与每日限额。

- 显卡：华硕、技嘉、微星。
- 内存：三星、金士顿、芝奇，关键词限定台式机或 DDR5。
- 固态硬盘：三星、西部数据。
- 处理器：AMD、英特尔。
- 主板：华硕、技嘉。
- 电源：海韵、海盗船。
- 散热器：利民。
- 机箱：联力。

京东使用现有精选商品池接口。普通关键词搜索不在当前已知权限范围内，
不能把池扫描描述成京东全站品牌搜索。每次最多扫描 30 页，遇到池末尾提前停止。

## 筛选与证据

- 优先按 API 品牌字段识别配件品牌；字段缺失时才参考标题。
- 内存颗粒厂商不等于内存条品牌，不能因标题含“三星颗粒”就算三星内存。
- 排除二手、拆机、翻新、服务器/笔记本配件、附件、订金与明显不适用品类。
- CPU、主板、显卡的套装价格单独排除，避免当作单件报价。
- 京东 `owner=g` 标记为京东自营；其他店不通过名称认定自营。
- 淘宝 `item_basic_info.user_type=1` 标记为天猫；导出不保留未确认天猫身份的淘宝条目。
- “旗舰店”“官方店”“天猫超市”等名称不能单独证明店铺身份。
  当前没有可信的品牌官方店铺 ID 名单，所以 `officialBrandStoreVerified` 保持 false。
- 商品展示价不是已核验具体 SKU 的成交价，`modelVerified=false`、`reviewRequired=true`。
- 按商品 ID 去重，保留不同店铺/商品的记录以供后续比价。

天猫标识、名称含官方旗舰店、名称为天猫超市均不单独通过可信店铺门槛。
后续只有将采集记录的卖家 ID 与品牌官网或平台认证证据对应后，才能加入官方店可信名单。
名称与品牌筛选仍可能误判，不能代替具体型号、容量、版本、店铺所有权及库存核验。

从项目根目录重新导出：

```powershell
server/.venv/Scripts/python.exe server/scripts/export_priority_hardware.py
```

可加 `--since-task <任务ID>`，统计该任务开始以来的采集次数和本轮候选数量。
