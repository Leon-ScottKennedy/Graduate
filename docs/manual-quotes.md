# 型号与店铺报价

不依赖京东、淘宝联盟 API 的本地报价路径。入口：智能装机 → 选中配件 → 店铺比价 → 录入 / 批量导入报价。

## 型号与价格依据

使用现有配置目录中的类别、品牌、完整型号和规格建立 `quote_models`，以完整字段生成稳定标识，严格隔离不同规格；这是用户确认关联，不是 AI 已验证匹配。录入前必须确认单件型号、容量及版本一致，不接受定金或套装价格作为单件报价。

可分别记录京东、淘宝/天猫店铺，价格口径为商品展示价 + 运费，不混入优惠券。来源明确区分人工录入和 CSV 导入。链接只接受对应平台的 HTTPS 商品页，清除跟踪参数，淘宝保留商品和 SKU 标识。平台链接仅供用户跳转，不会自动抓取详情。

记录保存在当前配置的 SQLite 数据库（默认 `server/storage/nexbuild.sqlite3`）的独立增量表，不覆盖已有 API 数据。相同型号、平台、店铺与商品链接视为同一报价；新价格增加快照，重复快照不重复写入。当前报价取查看时间最新的一条，后补录旧价格不会覆盖新价格。

## 比价与配置总价

同型号展示跨店含运费价格、差额、查看时间、价格历史和来源。超过 7 天的报价保留展示，但不参与最低价、有效店铺计数或采用报价。最低价仅覆盖录入的有效报价，不代表全网最低或实时可成交价。

“采用此店铺报价”只更新当前配件的计价，不改变型号或参数。配置清单标明采用的店铺，总价明确区分人工报价与其余参考价。用户可以恢复参考价，停用已采用报价也会恢复参考价。当前配置和采用状态沿用现有页面内存状态，刷新页面重新生成参考配置；保存的报价仍在数据库中，需要重新选择。预算/用途重新生成配置后也重新使用目录参考价。

原京东接口报价保留在折叠区，与人工报价分开，不进行未经确认的合并。

## CSV

每批最多 100 条，全部属于页面当前选中的完整型号。可下载 CSV 表头模板（不含虚构商品数据），使用 UTF-8 编码。

字段：`platform,shop,productUrl,price,shipping,observedAt,note`。

- `platform` 为 `jd` 或 `taobao`。
- `shop` 为店铺名称，`productUrl` 为完整商品链接。
- `price` 为正数，`shipping` 为非负数，均最多两位小数；包邮填 `0`。
- `observedAt` 需要时区，例如 `2026-10-19T10:00:00+08:00`。
- `note` 可留空，可记录颜色、盒装和价格条件。

后台先验证全批数据，再在事务中写入；错误行返回行号，整批不写入。

## 验证

52 项后端测试通过，包含型号隔离、跨店价差、最新查看时间、快照幂等、CSV 原子导入、错误链接/价格和过期处理。前端构建、目标文件 ESLint、兼容性/候选/选配回归检查通过。真实浏览器在独立测试数据库中完成京东手工录入、淘宝 CSV 导入、跨店比价、采用报价后总价变更、停用恢复参考价以及切换型号隔离；没有写入演示报价到正式库。
