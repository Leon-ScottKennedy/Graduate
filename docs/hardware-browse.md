# 硬件浏览目录

2026-10-19 增加“全部型号”入口，作为选中配件后的默认视图。它展示当前类别的全档位型号，并支持文本搜索和品牌筛选，不套用相近候选的同组、同芯片、同容量和 ±20% 价格限制。已知兼容冲突仍会阻止替换。

数据来源分开管理：

- 原自动选配目录 42 款及额外候选 43 款，共 85 款本地参考型号。
- 新增 30 款仅有官方规格来源的型号：CPU 13、显卡 9、SSD 8。位于 `src/data/hardwareExpansion.ts`，每款带 `specSource`。
- 浏览总计 115 款：CPU 25、显卡 24、主板 10、内存 10、SSD 18、电源 10、机箱 8、散热器 10。

新增资料只声明已列出的基础信息，不代表已取得完整尺寸、BIOS、功耗或性能测试；官方链接不能作为店铺库存或报价证明。

新型号的内部 `price=0` 是缺价哨兵，配合 `requiresQuote=true`，页面显示“价格待录入”，不会展示 0 元商品或直接计入配置。用户可展开型号的店铺报价，人工核对完整规格并录入/导入报价后采用，届时才参与整机总价。若这类型号的已采用报价被停用或恢复，返回该类别默认的有参考价型号，而不是把总价改成 0。人工报价在刷新页面后的采用状态仍遵循现有页面内存机制。

扩展目录不会进入原自动预算选配算法，也不凭空赋予相近性能分组。新型号未进入策划分组时，可继续在“全部型号”浏览和选配；“候选对比”仍使用原有严格规则。

官方来源包括 AMD Ryzen 产品/平台资料、Intel 桌面处理器参考表、MSI 显卡型号页、Samsung SSD 规格、Crucial T500 产品资料、Kingston KC3000 规格和 SanDisk SN850X 产品页。实际链接保存在每个新增型号的 `specSource` 中。

验证：`node scripts/test-hardware-browse.mjs` 检查型号去重、115 款计数、30 款缺价语义、来源链接、Intel/AM5 冲突与原目录不变；原候选和预算回归测试通过。独立数据库浏览器验证显卡 24 款、搜索、缺价型号录入报价后选配及恢复默认参考型号，未向正式数据库写入示例报价。
