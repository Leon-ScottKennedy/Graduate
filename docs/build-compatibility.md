# 替换前基础兼容检查

`buildCompatibility.ts` 为候选预览与实际替换入口提供同一套纯函数检查。候选冲突时按钮禁用并显示第一条原因；父页面再次检查，拒绝冲突替换且不改动配置或价格。成功替换后重新计算整机结果。

结果分为 errors（明确冲突）、warnings（建议提醒）、pending（资料不足）。只有 errors 禁用替换。检查 CPU/主板接口、DDR 代际、机箱支持的主板板型、已知散热器扣具、已知冷排尺寸、显卡长度和风冷高度。显卡推荐电源不足、CPU 预设供电/散热档位偏低进入 warnings，不判定硬件一定不兼容；预设档位不等于厂家认证或实测能力。

`PartOption.compatibility` 可逐步补充结构化接口、板型、支持冷排列表、显卡长度和散热器高度/限高等事实。未知数据进入 pending，不默认通过，也不填造尺寸。CPU 支持列表/BIOS、供电接头与线材、内存 QVL、冷排厚度和安装位置仍需核验。界面使用“基础检查无已知冲突”，不声称完全兼容。

基础结果同时展示整机原有冲突，因此更换无关配件不会被用来绕过已有冲突。显卡推荐功率只是整机建议，不是硬性最低要求；当前不计算精确整机功耗。电源升级不会自动进行，也不会擅自替换其他配件。

豆包在后台批量评估当前候选，用于排序和卡片内简短提示，不提供独立 AI 分析页面。接入、配置与限制见 [豆包接入说明](doubao-integration.md)。AI 不覆盖规则结果。

机箱冷排事实独立于板型：CH370 支持 360mm 冷排，不再被自动选配误排除；前置冷排可能挤占显卡空间，所以保留组合安装待核验。MATREXX 30 已知仅支持 120mm 冷排，不能装入 360mm 冷排。旧目录的先马 M2 没有完整安装资料，自动选配继续采用保守限制；基础检查不冒充已知厂家规格。

依据：[CH370 官方规格](https://www.deepcool.com/products/Cases/fulltowercases/CH370-Micro-ATX-Case/2022/15949.shtml)、[MATREXX 30 官方规格](https://uk.deepcool.com/products/Cases/2021/11923.shtml)、[AMD AM5 平台](https://www.amd.com/en/products/processors/chipsets/am5.html)。

验证：`npm run test:compatibility`，包含双向更换电源/显卡、接口/内存/板型冲突、尺寸超限、扣具、缺失信息、CH370 冷排回归、纯函数无副作用和 24 种自动配置。另运行候选覆盖与自动选配回归测试。
