# 硬件参考价

2026-10-24 补齐此前缺价的 53 个标准型号：CPU 13、显卡 22、主板 3、内存 5、SSD 10。价格与来源集中在 `src/data/referencePriceBook.ts`。

- 35 项公开参考：包含报价站参考值、渠道未税价、公开页面展示价和明确注明日期的历史价格。查阅日期不等于报价更新日期，也不保证当前仍有货。
- 1 项海外参考：芝奇 Flare X5 32GB DDR5 6000，使用页面人民币显示金额，另有运费和进口税等条件，未标为国内成交价。
- 17 项估算参考：缺少完整版本报价时，采用已查得的同品牌/同芯片同容量价格、同系列容量换算、型号比值或海外标价预算折算。每条记录保存锚点和方法，不把估算写成已采集报价。固定的7元/美元仅是预算换算常数，不是实时汇率。

例如，微星 5060 Ti 8GB VENTUS 2X OC PLUS 的公开参考为3199元；华硕 PRIME O8G 为3599元；技嘉 WINDFORCE OC 8G 为3499元；七彩虹战斧豪华版8GB为4499元。这些是来源页面的不同口径参考值，不代表同一时刻可成交的店铺价格，不为满足±15%筛选而修改。

`withReferencePrice` 只补缺价型号，不覆盖已有有效预设价格、用户记录报价或关联店铺价格；不修改原目录。当前候选与预算计算使用参考价，后来查询到的商品展示价另存为 `observedMarketOffer`，可以在来源详情中查看，不混入参考价比较。用户输入试算价时清除原参考价标签，避免把试算标成公开价格。

前端可展开“公开参考价来源 / 估算参考价依据 / 海外参考价来源”查看链接、查阅日期和说明。参考库不会生成店铺ID、商品报价或手工确认记录；SQLite中的平台报价、原始响应和历史记录保持原有含义。

同档比较默认最多加价15%；符合规格与兼容条件的便宜型号不限降价幅度，直接展示。只有超过加价上限的型号需要切换“全部价位”。拥有参考价不代表已核验完整兼容性，原兼容性规则仍执行。

验证：`npm run test:reference-prices`、`npm run test:candidates`、`npm run test:optimization`、`npm run build`。
