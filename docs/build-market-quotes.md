# 自动选配与商品报价

智能装机页初始化时加载本地型号库和扩展型号，再通过
`POST /api/market/catalog-offers` 批量查询最近七天内的型号匹配报价。
该接口只读取采集库，不会在用户拖动预算滑块时请求电商平台。

匹配到的正数商品展示价写入页面会话的配件选项，并保留 `marketOffer`：
商品 ID、店铺、平台、商品链接与采集时间。它不等于已核验成交 SKU，也不包含运费、
国补资格或其他条件优惠。未匹配的扩展型号继续保持 `requiresQuote=true`，不能按零元选配。

自动选配始终以用户预算及用途确定目标支出，不因采集库只有低价显卡就缩减目标。
有记录报价的配件获得少量排序加分，不能覆盖明显的档位与预算分配差距。
有效预设参考价仍可参与选配，页面明确区分已记录报价和参考价。
没有价格的扩展型号不能参与选配；不会为它编造报价或店铺链接。

无论哪个分支，总价都不得超预算；最终组合执行兼容性明确冲突检查。
资料缺失和警告不等于已经完全兼容。手动替换仍允许超预算，并显示超额。

显卡匹配分别核对品牌、芯片、显存、系列/版本标识，允许显存位置变化和末尾营销文案。
不同芯片、8GB/16GB、OC/非 OC、二手、整机和明显混卖链接不会合并成同款报价。
SSD 容量解析同时识别 TB/T 和 GB/G，避免把“2TB/4T/1T”当成单一 2TB 链接。

店铺比较与自动选配使用同一套匹配服务，允许京东及天猫第三方商品，
自营/已核验身份优先。带 `marketOffer` 的候选可直接打开该商品链接。
没有实际商品记录时不能凭空生成店铺或商品 ID。

## 2026-10-24 跨品牌同档补采记录

同档替换现在独立调用 `/api/market/alternatives`，不调用豆包。先读库，再按不同品牌优先补采，已知价格默认限制 ±15%。未知价格仅展示待报价型号，不参与价差计算或替换。

本轮检查 GPU 6、主板 6、内存 4、SSD 6，共 22 个候选型号；尝试京东关键词与淘宝接口。京东关键词接口返回 403，部分淘宝查询失败或没有准确版本。匹配到的微星 5060 Ti 8GB 进口展示价 11312 元、海盗船 DDR5 6000 32GB 展示价 1499 元均不在当前配件价格的 ±15% 内，不能作为本轮合适候选。不得把它们改写成预期价格。

另外调用京东精选池三页，返回 150 条、3 条有效硬件记录，任务 `ab81a11968704c998991a949ba8f62e6`。这不代表新增三条匹配当前候选的报价，也不代表已补齐所有品牌。原始响应和清洗记录保留在数据库。

型号匹配补充华硕雪豹/Dual、大师/Prime 以及 O8G/OC 版本表达，内存补充海盗船复仇者/VENGEANCE。RAM/SSD 将容量、DDR、频率与型号身份分开核验，允许零售标题调整属性顺序，不放宽到不同容量或不同 DDR/频率。
