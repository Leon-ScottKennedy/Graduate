# 京东 / 淘宝统一商品参考

候选选择修正：默认使用同类配件完整目录，按与当前参考价的距离排序，取消同芯片、同核心组、同功率和固定 ±20% 的交叉门槛。候选标签内可筛选 ±20% / ±35% / ±50%、品牌和关键词，不再新增独立“全部型号”标签。旧同规格比较函数保留用于严格规格比较及回归，不作为购物候选默认规则。

资料库中缺价格的型号排在已知价格之后，显示“价格待确认”，不能按零元替换或进入指定价位筛选。所有型号都可从候选卡片查看店铺，预览不会更改整机选配。兼容性冲突仍阻止替换，价格相近不代表性能相同。自动预算选配继续使用原目录与约束，不因扩大浏览候选而改变。候选、兼容性、144 组预算组合回归及前端构建通过。

浏览与采集分离（最新行为）：取消本地空结果时的自动补查，切换配件、平台和本地分页只读数据库，不受任何电商查询冷却影响。真实代理请求验证连续 GPU → CPU 本地查询均为 HTTP 200，合计约 0.07 秒。远程更新只在显式点击或独立批量脚本中执行；界面更新优先使用天猫筛选。

`collect_taobao_models.py --tmall-only --pages 2` 可对最多 8 个关键词各采集最多 3 页，每次间隔 11 秒，持续使用相同数据库的日限额和任务互斥。返回空页或到达总页数后不继续该关键词；权限、网络或其他平台错误仍停止。已核实的平台 `15:50001` 无结果作为空结果成功缓存，避免误触发失败冷却。天猫筛选缓存与全平台缓存分别保存，旧数据库自动添加 `tmall_only` 字段，保留历史数据。店名带“专卖店”也加入优先排序，但不伪装为官方身份认证。

本轮首批 16 页查询返回并保存 185 条商品记录，覆盖 AMD、金士顿、三星、微星、海盗船等；再以 4 次单页查询补充微星 RTX 5070、华硕 RTX 5060、技嘉 RTX 5080、蓝宝石 RX 9070，收到 74 条。合计 259 条记录已保存。仅代表收到的商品记录，不能视为 259 条精确型号报价；7700、4070 SUPER、4080 SUPER 目前仍未取得合格的对应天猫单型号报价。历史下文的“本地缺失自动补查”流程已被本节替代。

预设型号与真实店铺的查询流程修正：装机目录仍是本地预设参考型号，不代表平台在售。聚合接口返回标准搜索关键词（如 `微星 RTX 4080 SUPER`，去掉 VENTUS 3X OC 等厂商版本词）及京东、天猫官方站内搜索 URL。店铺比较先读本地，仅当本地为空且淘宝已配置时自动补查一页，继续沿用持久化缓存、限流和每日上限，不自动翻页、轮询或重试；手动更新也使用标准关键词。仍为空时显示对应平台搜索入口，它们是搜索页面而非已验证的店铺报价。

本次 `微星 RTX 4080 SUPER` 单次返回并入库 6 条；实际均为混合型号议价商品，严格筛选后没有符合条件的 4080 SUPER 单型号报价，未伪造成功。新增测试覆盖标准关键词、空库站内搜索链接；原有芯片隔离、店铺优先及品牌/成色过滤继续生效。

店铺排序更新：有效且未过期的商品先按店铺优先级，再按型号匹配和价格排序。京东 `owner=g` 标为京东自营；淘宝搜索 `item_basic_info.user_type=1` 标为天猫。天猫带旗舰店/官方店名称的店铺与京东自营优先，淘宝店名带旗舰店/官方店的其次，再排其他天猫和京东店铺，普通淘宝店铺在后。名称只作为排序线索，不作为官方身份认证；没有认证徽章。相同平台、店铺、完整标题的轮换联盟 ID 在展示时复用最新记录，原始数据全部保留。

入口：智能装机 → 选中配件 → 店铺比价 → 京东 / 淘宝商品参考。

`POST /api/market/compare` 接受 category、brand、modelName、specs，以及可选 platform（all/jd/taobao）和 page。只读取本地数据库，不调用远程接口。跨平台商品分别保留，以平台商品 ID 去重，取最新展示价；最新价格无效时不回退历史低价。标题规格匹配优先，同组按价格排序，每页 30 件；超过 7 天提示更新。已知不一致类目排除，其他相关型号商品标记为待确认；列表不将 API 商品参考自动计入装机总价，确认报价仍使用原有人工录入入口。

“补充淘宝商品”按当前型号查询一页，“再补充一页”手动继续，沿用 15 分钟缓存、10 秒间隔、失败 60 秒冷却、滚动 24 小时 100 次上限。切换型号、平台、列表分页只查询本地。京东原有刷新数据池和价格历史入口保留。

2026-10-20 使用官方淘宝接口完成 8 个关键词各一页的小批次采集，间隔 11 秒，返回并清洗 97 条，当前数据库淘宝去重商品 97 件、京东 42 件，总计 139 件；这不是同型号有效报价数量。原始记录、采集时间和历史快照均保留。示例本地查询：7500F 有 5 件淘宝参考，RTX 4070 SUPER 有 17 件淘宝参考，已知不同类目被排除。
