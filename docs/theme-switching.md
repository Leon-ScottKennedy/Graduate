# 明暗主题

右上角太阳/月亮按钮切换全站主题，暗色保持为默认外观。用户选择保存到`localStorage`的`nexbuild-theme`，页面加载样式之前由`public/theme-init.js`恢复，避免刷新时闪回暗色。存储不可用时仍能在当前页面切换；其他标签页的主题选择会同步。

`ThemeToggle.vue`提供太阳/月亮、星星/云朵及滑动动画。有View Transition能力时，以按钮为圆心展开新主题；不支持该动画或启用减少动态效果时直接切换。支持键盘操作和读屏状态。按钮固定在右上角，与左上角导航及右下角助手分开。

配色通过`vite.config.ts`注册的`scripts/theme-colors.mjs`处理：为已有CSS颜色生成`light-dark(亮色值, 原暗色值)`。按文字、背景、边框、阴影的角色生成亮色配对，原暗色值原样保留。该方法覆盖全局CSS、懒加载页面和Vue组件样式，无需运行时遍历DOM，也不对整个页面做反色滤镜。图片、SVG属性、数据图表的原始颜色和遮罩不会被反色。红绿差价等语义色在亮色下采用较深的同色系以保持可读。

`ThemeToggle.vue`自身的天空/夜空配色和`theme.css`明确指定的主题样式不再自动转换。新增需要固定原色的组件可在转换器排除列表中登记。首页Canvas网格订阅主题变更事件重新绘制；其他Canvas如以后引入，也应使用相应主题色重绘。

主题配色使用现代浏览器支持的CSS `light-dark()`（主流浏览器2024年起支持）。状态管理位于`src/services/theme.ts`，初始化在`src/main.ts`挂载应用之前完成，CSS配色由`color-scheme`统一控制。

验证命令：`npm run test:theme`、`npm run build`。主题测试检查保存/默认/存储受限启动、整站样式处理、暗色原值保留，以及遮罩和图片资源不被改写。
